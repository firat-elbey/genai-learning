✂️ Level 1 — Tokens: text becomes pieces

A language model can't read letters. Step one is a tokenizer that chops your text into tokens — frequent words stay whole, rare words get built from smaller pieces. Each token is just an ID number pointing into a vocabulary. This tokenizer is a real BPE tokenizer, trained right in your browser on this app's tiny corpus. 🧭 Level 2 — Vectors: pieces become numbers

Each token ID looks up an embedding — a list of numbers (here 48, in big models thousands) that is the token's meaning to the model. These were learned from which words appear near which: similar use ⇒ similar vector. Because attention has no sense of order, a positional encoding is added so each vector also knows where it sits in the sentence. Click a token below to inspect its vector.

🔦 Level 3 — Attention: the tokens talk to each other

After Level 2, every token is a vector that knows its own meaning and position — but nothing about its neighbors. In “the cat sat”, the vector for sat has no idea who sat. Self-attention is the step that fixes that, and it works like a matchmaking round between all tokens:

  1. Every token publishes a query — a small vector meaning “what I'm looking for”. (In a trained model, sat might effectively ask: “is there a noun just before me?”)
  2. Every token also publishes a key — “what I can offer”. (cat might advertise: “I'm a noun, an animal.”)
  3. Each query is compared with every earlier key by a dot product: multiply the two vectors element by element and add it all up. Vectors pointing the same way ⇒ big score. That's the whole matching mechanism.
  4. The scores are divided by √12 (just to keep numbers tame) and pushed through a softmax, which turns them into percentages that add up to 100%. Those percentages are exactly the bright/dark cells in the map below.
  5. Each token then updates itself with a weighted mix of the other tokens' values (“the information I hand over if you pick me”) — mostly cat's value, if cat won the match. Now sat knows who sat.

This happens 4 times in parallel per layer (the “heads”, each with its own learned matrices, so each head develops its own notion of relevance) and across 3 layers. The empty upper-right triangle of the map is the causal mask: a token may never look at tokens after itself, because during generation the future doesn't exist yet. (One honest caveat: this toy's matrices are random, so its heads have arbitrary preferences — in a trained model they specialize into roles like “look at the previous noun”.)

⚡ Level 4 — Neurons: patterns light up

After attention, each token's vector runs through an MLP — a bank of 96 neurons per layer here (tens of thousands in big models). Each neuron checks the vector against its own learned pattern; the GELU squashes weak matches to ≈0, so only some neurons fire. These grids are the activations — the “brain scan” of the model. Below that, the residual stream: the same token's vector after each layer. Blocks don't replace the vector, they add refinements to it. Click a token, compare layers.

🎲 Level 5 — Prediction: scores become odds

The final vector of the last token is compared against every token in the vocabulary, producing a score (logit) for each. A softmax turns scores into probabilities. The model's true output is this whole distribution — picking one token is a separate sampling step. Temperature reshapes the odds before the draw. Drag the slider and watch the bars; then roll the dice.

🔁 Level 6 — Generation: the loop that writes

One forward pass = one token. To write text, the model loops: predict → sample → append → run again on the longer sequence. Every reply you've ever seen from an LLM was produced by exactly this loop. Watch it live — each new token shows the probability it was drawn with. Expect toy-model poetry: it repeats and drifts, because it's tiny and untrained. The mechanism is the real thing.

About what you just learned

This toy differs from GPT-class models only in scale and training: real models have the same tokenizer idea (≈100k tokens), the same attention/MLP/residual blocks (×dozens of layers, ×dozens of heads, ×thousands of dimensions), the same softmax sampling loop — plus months of gradient descent on trillions of tokens. Here, the transformer weights are random (honesty!) and readable behavior comes from corpus statistics blended into the logits. The math you watched, though, is the real forward pass, computed live in your browser in ~5 ms.
